📌 SkillMirror – GitHub Skill Analyzer

SkillMirror is a web application that analyzes a user’s public GitHub repositories and displays their actual technical skills using real data and visual charts. 
Instead of assuming skills from resumes, SkillMirror shows proof-based skills derived from GitHub activity.

🎯 Why I Built This Project

  Many people mention skills in their resumes without real evidence.

 I built SkillMirror to:

  Validate skills using real GitHub work.
  Avoid assumptions and show data-driven results.
  Help recruiters and learners understand actual skill usage.

🧠 How It Works

   1. User enters a GitHub username
   2.App fetches public repositories using GitHub API
   3.Programming languages are analyzed from repos
   4.Skills are categorized and counted
   5.Results are displayed using interactive charts

🚀 Features

   🔍 GitHub profile analysis
   📊 Visual skill charts (Pie / Bar)
   🏆 Auto-highlight top skill
   📱 Responsive UI (desktop & mobile)
   🌐 Live deployed application

🛠 Tech Stack

   Frontend: HTML, CSS, JavaScript, Chart.js
   Backend: Python, Flask
   API: GitHub REST API
   Deployment: Render
   Version Control: Git & GitHub
